# 👗 AIFashion: AI-Powered Style Explorer

AIFashion is a modular fashion discovery web application that blends **personal style** with **AI remixing**, enabling users to explore and customize trending looks.  
The platform integrates **Cloudinary** for dynamic image transformations and **Gemini API** for intelligent style suggestions, delivering a personalized fashion experience.

---

## ✨ Features
- 🔍 **AI-Powered Style Suggestions** – Gemini API provides intelligent recommendations tailored to user preferences.
- 🎨 **Interactive Trending Page** – Explore and remix trending looks with responsive UI components.
- 📸 **Dynamic Image Transformations** – Cloudinary integration for real-time image editing and optimization.
- ⚡ **Optimized Performance** – Achieved 35% faster image rendering and reduced backend latency with FastAPI.
- 📈 **Enhanced Engagement** – Improved user interaction by 50% through remixable features and modern UI design.
